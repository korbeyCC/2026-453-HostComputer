# 2026-453 多轴升降同步监控上位机 (60 FPS 电竞级极速版)

专为 **2026-453 多柱同步升降控制系统** 定制开发的高性能、高刷新率物理串口监控与数据可视化分析工具。遵循现代化扁平风格设计，具备无阻塞多线程双轨流式解析引擎与 60 FPS 极速示波器。

---

## 核心特性

1. **60 FPS 高帧率极速示波器**
   - **四轴高度差曲线（H0~H3）**：实时解算四轴相对于当前平均高度的差值 $\Delta h_i = H_i - H_{\text{avg}}$，形成围绕平均高度基准中轴交替缠绕纠偏的动态波形。
   - **固定中心平均高度基准线**：中轴物理位置稳固在画布 50% 垂直中心，上方动态显示实时绝对平均高度及毫米折算值（`Avg: {counts}c ({mm}mm)`）。
   - **误差量程实时缩放（mm 输入）**：支持直接输入毫米单位的误差量程（默认 `5.0mm`），程序根据系统物理参数（$112.5\text{ counts/mm}$）自动完成脉冲换算与等比缩放。
   - **多物理量同屏对比**：支持轴间差值（MaxDiff）、4 轴转速（V0~V3）、4 轴电流（I0~I3）自由勾选叠加显示。

2. **双轨无损流式通信与数据解析**
   - 具备 78 字节二进制高密度数据帧与 ASCII 阶段性提示文本的自适应双轨流式分离解析机制。
   - 杜绝传统串口助手在高波特率（115200 bps）高频采样下的白屏、掉帧与卡顿问题。

3. **关键运行指标与结构化日志**
   - 实时监控目标差值、当前差值、最大差值（Peak 峰值保持）以及系统状态机步骤。
   - 结构化富文本日志窗口，支持电机采样停更/掉帧高亮预警及错误状态快速排查。

## 快速开始

### 方式 1：直接运行预编译版本（免环境）
直接双击运行本项目下的打包程序即可：
```text
dist/data_analyzer.exe
```

### 方式 2：使用 Python 源码运行
1. 安装依赖库：
   ```bash
   pip install pyserial
   ```
2. 启动上位机：
   ```bash
   python src/data_analyzer.py
   ```

### 方式 3：重新编译打包
双击运行根目录下的 `build.bat` 或在终端执行：
```bash
python -m PyInstaller --clean --noconsole --onefile src/data_analyzer.py --name "data_analyzer"
```
构建产物将自动输出至 `dist/data_analyzer.exe`。
